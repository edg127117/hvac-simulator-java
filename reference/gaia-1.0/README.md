`python-reference-plot.png` 使用同一份冻结 CSV 重新渲染，只配置 Windows 黑体解决中文缺字，不改变数据、三联布局、颜色或曲线。

## 已知兼容边界

- 气象季节从仿真第 0 天开始，而不是实际日期的年内日序。
- 冷机停机时 COP 为 0。
- 基准中设备每次连续运行 1 分钟，功率和 COP 呈尖峰。
- 管道热量符号和回水温度沿用原实现。

第一阶段只忠实转换这些行为，不在同一任务中修正模型。
