# Gaia 1.1 可配置仿真与中央空调 MQTT 平台 MVP 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 先冻结并忠实转换 Gaia 1.1，再交付一个可选择 Gaia 1.0/1.1、可修改真实计算参数、可监控运行、查看曲线并通过 MQTT 向现有中央空调平台回放真实测量结果的最小完整纵向切片。

**Architecture:** 实施顺序严格分为“Python 参考 → Java 引擎 → Spring Boot 应用 → Vue 工作台 → MQTT 目标适配 → 中央平台验证”。Gaia 计算包保持纯 Java；Spring Boot 只负责任务编排、进程内任务仓库、结果查询和发送；Vue 只调用应用接口；MQTT 适配器只消费已完成 Java 结果并映射现有中央平台契约。

**Tech Stack:** Python 3.12、NumPy 2.3.5、pandas 3.0.1、Matplotlib 3.11.1、Java 21、Maven Wrapper、Spring Boot 4.1.0、Eclipse Paho MQTT 1.2.5、Vue 3.5.40、Vite 8.1.5、TypeScript 5.9.3、Apache ECharts 6.1.0、Vitest 4.1.0、Playwright 1.58.2。

### 2.3 Spring Boot API

基础路径固定为 `/api`：

| 方法与路径 | 作用 |
|---|---|
| `GET /api/model-releases` | 返回 Gaia 1.0/1.1 版本、状态和默认模式。 |
| `GET /api/model-releases/{version}/parameters?mode=BASELINE|SCENARIO` | 返回分组、真实默认值、单位、范围、参与计算和可修改状态。 |
| `POST /api/simulation-runs` | 创建不可变参数快照并异步运行。 |
| `GET /api/simulation-runs/{runId}` | 返回 `QUEUED/RUNNING/COMPLETED/FAILED`、进度、模拟时间、错误和产物。 |
| `GET /api/simulation-runs/{runId}/series?codes=...` | 返回图表时间轴和已登记序列。 |
| `GET /api/simulation-runs/{runId}/rows?offset=0&limit=200` | 分页返回真实结果行。 |
| `POST /api/simulation-runs/{runId}/mqtt-deliveries` | 从已完成结果创建 MQTT 回放。 |
| `GET /api/simulation-runs/{runId}/mqtt-deliveries/{deliveryId}` | 返回发送总数、成功、失败、状态和错误。 |

创建任务请求：

```json
{
  "modelVersion": "gaia-1.1",
  "mode": "SCENARIO",
  "parameterOverrides": {
    "hvac.cooling_setpoint_c": 24.5,
    "measurement.temperature_noise_std_c": 0.15
  }
}
```

基准模式有任何覆盖值时返回 400；场景模式的未知、锁定、未参与计算、错误类型、错误单位或越界值返回稳定中文错误。任务创建返回 HTTP 202 和 `runId`。

### 2.4 MQTT 中央平台目标映射

中央平台现有主题为 `device/data/up`，QoS 1、retain=false；载荷固定为：

```json
{
  "buildingId": "BLD001",
  "deviceId": "WCR1",
  "pointCode": "WCR1_TWin",
  "val": 12.3,
  "timestamp": 1785398400000
}
```

只发送以下真实测量字段：

| Gaia 1.1 字段 | 目标点码 | 转换 | WCR_COP 语义 |
|---|---|---|---|
| `T_chw_return_sensor` | `WCR1_TWin` | 原值 ℃ | 冷冻水进机组/回水温度 |
| `T_chw_supply_sensor` | `WCR1_TWout` | 原值 ℃ | 冷冻水出机组/供水温度 |
| `chw_flow_sensor` | `WCR1_Flow` | `m³/s × 3600` | 冷冻水流量 m³/h |
| `chiller_power_kW` | `WCR1_PPE` | 原值 kW | 冷机实测功率 |

不发送 Gaia 无法提供的电压、电流、功率因数、压力或 AHU 测点。中央平台按现有公式计算：

```text
WCR_COP = Flow(m³/h) × 1000 × 4.18 × (TWin - TWout) / 3600 / PPE(kW)
```

其数值应与同一时间步 `measured_COP` 在浮点容差内一致。

MQTT 回放支持：

- `SIMULATION_TIME`：使用原模拟时间；
- `REBASE_TO_NOW`：将选择范围第一分钟映射到最近已结束分钟，其余时间保持相对间隔，用于当前中央平台趋势验收；仿真平台仍保存原 `simulationTime`，不能把重映射时间写回模型结果。
