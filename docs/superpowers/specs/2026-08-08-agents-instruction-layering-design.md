# AGENTS 指令分层整改设计

## 状态

已确认，进入实施。

## 背景与问题

Codex 从仓库根目录启动任务。当前根 `AGENTS.md` 为 14,962 字节，尚未单独超过默认指令限制，但包含大量通用 Git、详细仿真验证、注释和信息维护说明。随着 Gaia 1.1 和正式平台继续演进，继续把全部细则叠加在根文件中会增加每次任务的固定上下文并形成重复维护。

## 目标

- 根 `AGENTS.md` 作为始终加载的短规则和按需文档路由，目标不超过 8 KiB。
- 完整保留 Gaia 忠实转换、确定性仿真、数值容差、图表验收和禁止静默修模等关键边界。
- 详细仿真验证和注释规则按主题存入普通文档。
- 不修改 Java 代码、参考资产、测试、构建、模型行为或项目当前状态。
- 不为尚未实现的 engine、server、web 创建子目录规则。

## 文件职责

| 文件 | 整改后职责 |
|---|---|
| `AGENTS.md` | 强制读取顺序、核心 Git 边界、Gaia 模型硬约束、条件式开发文档路由和最低交付要求 |
| `PROJECT_GUIDE.md` | 稳定项目目标、当前 CLI 架构、模型版本、数据链路、命令和文档导航 |
| `PROJECT_STATUS.md` | 当前实现、未完成项、风险和下一步；本次不改变项目状态 |
| `docs/development/simulation-verification.md` | 基准冻结、逐时间步对照、容差、边界、输出和图表验收完整规则 |
| `docs/development/code-comments.md` | Java 仿真代码的职责、公式、单位、状态更新和注释检查完整规则 |

## 规则迁移映射

- 原 Git 章节压缩为根规则，保留分支、暂存、提交、推送、PR 和禁止操作的硬约束。
- 原测试章节迁入 `simulation-verification.md`，根规则保留任何模型任务必须读取该文件的触发条件。
- 原注释章节迁入 `code-comments.md`，根规则保留生产代码改动必须完成注释检查的要求。
- 原信息分层章节压缩为根路由，继续由 `PROJECT_GUIDE.md` 和 `PROJECT_STATUS.md` 分别承载稳定事实和动态状态。

## 验证与验收

- 根 `AGENTS.md` 不超过 8 KiB，与个人全局规则合计显著低于 32 KiB。
- 新增文档链接均存在并可从根目录解析。
- Gaia 1.0/1.1、忠实复现、随机基准、逐时间步、容差、图表和禁止静默修正等关键语义均可定位。
- `git diff --check`、Markdown 路径和无关文件检查通过。
- 本次纯文档整改不运行 Java 业务测试，避免把未变化代码的测试结果误写为本次实现证据。

## 非目标

- 不实施 Gaia 1.1 或正式仿真平台。
- 不拆分仓库或预建 engine、server、web 规则。
- 不调整 Codex 全局配置、模型、子代理或项目代码。
